# ALIYO-MOMOT-UNIVERSITY
A UNIVERSITY SPECIALIZING IN MEDICAL AND ENGINEERING EDUCATION

## 🎓 University Web Application

This repository contains the official web application for ALIYO MOMOT UNIVERSITY, showcasing our commitment to excellence in medical and engineering education.

## 📋 Features

- **Responsive Design**: Fully responsive website that works on desktop, tablet, and mobile devices
- **Modern UI**: Beautiful gradient designs and smooth animations
- **Interactive Navigation**: Smooth scrolling and active navigation states
- **Campus Gallery**: Features images of campus buildings (aliyo-momot-2.jpg and aliyo-momot-3.jpg)
- **Program Information**: Detailed information about medical and engineering programs
- **Contact Information**: Easy access to university contact details

## 🏗️ Application Structure

```
ALIYO-MOMOT-UNIVERSITY/
├── index.html          # Main HTML file

```

## 🚀 Getting Started

To view the application:

1. Open `index.html` in a web browser
2. Navigate through different sections using the navigation menu
3. Explore our programs, gallery, and contact information

## 📱 Sections

- **Home**: Welcome section with call-to-action
- **About**: University overview with statistics
- **Programs**: Medical and Engineering program listings
- **Gallery**: Campus images featuring Building 2 and Building 3
- **Contact**: University contact information
